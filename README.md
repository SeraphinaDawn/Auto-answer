# 智慧职教自动答题机器人

这是一个用于自动完成智慧职教平台上的答题的 JavaScript 脚本。它使用 GLM-4 API 来获取答案，并自动点击选择题和判断题的选项，最后提交试卷。

## 功能特点

*   **自动获取答案：** 通过调用 GLM-4 API，根据题目内容获取答案。
*   **支持多种题型：** 支持单选题、多选题和判断题的自动作答.
*   **模拟用户操作：** 自动点击选项，并有随机延迟，模拟真实用户操作.
*   **自动提交试卷：** 完成所有题目后，自动滚动到底部并点击提交按钮.
*   **可配置 API 密钥：** 需要替换 `API_KEY` 为你的 GLM-4 API 密钥.

## 代码结构

### `AutoAnswerBot` 类

这个类包含了自动答题的所有逻辑。

*   **构造函数 `constructor()`：**
    *   初始化 `API_KEY` 和 `API_URL`。
*   **`getAnswers(questions)` 方法：**
    *   接收题目数组，构造请求 GLM-4 API 的 prompt.
    *   发送请求，获取 API 返回的答案.
    *   解析 API 返回的答案，以题号为键，答案为值的对象形式返回.
*   **`autoAnswer()` 方法：**
    *   获取页面上所有题目元素.
    *   收集题目信息，包括题号、题目文本、题目元素等.
    *   调用 `getAnswers()` 方法获取所有题目的答案.
    *   遍历题目，根据答案类型点击相应的选项.
    *   模拟滚动到底部并点击提交按钮.
*   **`randomDelay(min, max)` 方法：**
    *   生成指定范围内的随机延迟，用于模拟用户操作.

### 主要步骤

1.  **获取题目：** 通过 `document.querySelectorAll("[id^='qContent']")` 获取页面上所有的题目元素。
2.  **构建 Prompt：** 将所有题目的文本拼接成一个 prompt，发送给 GLM-4 API。Prompt 的格式如下：

    ```
    你是一个专业的答题助手。下面是一套试题，请帮我回答，根据每道题的类型，返回相应的答案。
    
    - 对于单选题，返回选项字母，如"1:A"
    
    - 对于多选题，返回多个选项字母，用逗号分隔，如"21:A,B,C"
    
    - 对于判断题，只返回"正确"或"错误"，如"26:正确"
    
    请按照题号顺序回答，每题答案占一行。
    
    试题内容：
    [题目1文本]
    [题目2文本]
    ...
    ```
    
    这个 prompt 指示 GLM-4 返回特定格式的答案，包括单选题的选项字母，多选题的选项字母列表，和判断题的 "正确" 或 "错误"。
3.  **请求 API：**  使用 `fetch` 发送 POST 请求到 GLM-4 API，请求头包含 API 密钥，请求体包含 prompt。
4.  **解析答案：** 解析 API 返回的文本，提取题号和答案。
5.  **自动答题：** 遍历题目，根据答案类型（单选、多选、判断）点击相应的选项。
    *   **单选题：** 根据答案字母 (A, B, C, D) 找到对应的选项并点击。
    *   **多选题：** 将答案拆分成字母数组，并依次点击对应的选项。
    *   **判断题：** 根据 "正确" 或 "错误" 点击对应的选项。
6.  **提交试卷：** 滚动到底部并点击提交按钮。

## 如何使用

1.  **替换 API 密钥：** 将 `this.API_KEY = "";` 替换为你的 GLM-4 API 密钥。
2.  **复制粘贴：** 将整个代码复制粘贴到智慧职教的答题页面的浏览器控制台（Console）。
3.  **运行：**  按下回车键运行代码。

## 注意事项

*   请确保你已经拥有有效的 GLM-4 API 密钥。
*   此脚本仅用于学习和研究目的，请勿用于非法用途。
*   请注意，由于网络延迟等原因，自动答题可能并非 100% 成功。
*   **特别注意：** **因为我没有进行别的课程的测试，所以别的课程页面元素可能不一致，比如题目id，选项的class等，如果无法正确运行，你需要自行查找并修改对应的选择器 (例如 `document.querySelectorAll("[id^='qContent']")` 或 `.q_option div[onclick*="'${value}'"]`)。**
